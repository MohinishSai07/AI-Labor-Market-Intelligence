# 🤖 AI Labor Market Intelligence

An interactive Power BI dashboard designed to analyze the AI labor market across jobs, skills, salaries, locations, and hiring companies.

## 📊 Project Overview

This project transforms AI job-market data into an interactive analytical dashboard that provides insights into hiring demand, in-demand skills, salary patterns, geographic distribution, and company hiring activity.

The dashboard contains six analytical pages, each focused on a different aspect of the AI labor market.

## 🔎 Key Analysis Areas

- AI job demand and hiring patterns
- In-demand AI skills
- Salary and compensation analysis
- Geographic hiring distribution
- Company hiring activity
- Executive-level market insights

## 📑 Dashboard Pages
 
1. Overview - Overall AI labor market
2. Skills - Skills demand and skill-driving companies
3. Salary - Compensation and highest-paying roles
4. Location - Geographic hiring and salary patterns
5. Company - Company hiring and salary landscape
6. Executive - Key metrics and executive insights

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization
- Exploratory Data Analysis

## 📈 Key Insights

- Analysis covers 291 AI job postings.
- The dataset includes 206 companies and 38 locations.
- Machine Learning, Python, and SQL are among the most demanded skills.
- Salary analysis highlights substantial differences across AI roles and companies.
- Geographic analysis reveals concentrated AI hiring activity across major US locations.

## 📌 Project Objective

The objective of this project is to turn raw AI job-market data into clear, interactive, and decision-oriented insights using business intelligence and data visualization techniques.
